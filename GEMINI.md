# AGENTS.md

## Always Use

For every task in this project, use the following skills and references:

- `tailwind-4-docs`
- `web-design-guidelines`

## Design Rules

- Read and follow `DESIGN.md` before making any changes.
- `DESIGN.md` is the single source of truth for:
  - Layouts
  - Styling
  - Components
  - Typography
  - Spacing
  - Colors
  - Responsiveness
  - Accessibility
  - Animations and interactions

## Development Guidelines

- Preserve the existing project structure.
- Reuse existing components whenever possible.
- Follow established coding patterns and conventions.
- Keep code clean, modular, and maintainable.
- Avoid unnecessary dependencies or architectural changes.

## UI/UX Standards

- Prioritize clean and minimal design.
- Maintain visual consistency across all pages.
- Ensure responsive behavior on all screen sizes.
- Follow the design system and patterns defined in `DESIGN.md`.

## Validation Checklist

Before completing any task, verify that:

- [ ] `DESIGN.md` guidelines have been followed.
- [ ] The implementation uses the required skills.
- [ ] No existing functionality is broken.
- [ ] The UI is responsive and accessible.
- [ ] The design remains consistent with the project.

## Important

If there is any conflict or uncertainty:

1. Follow `DESIGN.md`.
2. Use `tailwind-4-docs` and `web-design-guidelines`.
3. Do not make design assumptions that are not defined in `DESIGN.md`.
4. Any implementation that does not comply with `DESIGN.md` should be considered invalid and must be revised.
